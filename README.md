# AI Agent Trader — public dashboard

This repository contains only the sanitized, static GitHub Pages output for the
AI Agent Trader paper-trading dashboard. It contains no trading implementation,
broker credentials, account identifiers, or order identifiers.

The private source repository publishes `site/` after a successful read-only or
paper-forward account build. The Pages workflow verifies the static allowlist
and versioned public contract before deployment. Paper results use fake money,
simulated broker fills, and are neither live results nor financial advice.
